# @caustic/react for agents

Before building UI with this package, load the `caustic` skill (install it with `npx caustic init`) and use the `caustic` CLI (`@caustic/cli`).
Run `caustic` for status, `caustic find "<need>"` and `caustic list --tree` to pick components, `caustic show <ids> --depth api` for their API.
Style with token utilities only (no literals, no `dark:`), then run `caustic check <files>` and fix every error.
